# Azure App Service build manifest for the CSR Co-Pilot deploy.

# standard library -- http.server, ssl, os, subprocess, sys -- so nothing

# 'anthropic' is included so the optional server-side Claude proxy endpoint
# (the secure way to do document extraction without exposing a key in the
# browser) works the moment you add it -- no second dependency change needed.
# It's a lightweight pure-Python package and harmless if left unused.
